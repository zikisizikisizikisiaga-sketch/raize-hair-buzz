# RAIZE HAIR BUZZ ホームページ

沖縄県那覇市与儀の理容室「RAIZE HAIR BUZZ」の公式ホームページです。

- GitHubリポジトリ（このページ）: https://github.com/zikisizikisizikisiaga-sketch/raize-hair-buzz

## フォルダの中身

- `index.html` … ページ本体
- `css/style.css` … デザイン
- `js/main.js` … メニュー開閉・ギャラリーの動き
- `images/` … 写真・QRコードなど

## ローカルで確認する方法

```bash
python3 -m http.server 8123 --directory "."
```

を実行し、ブラウザで `http://localhost:8123/index.html` を開く。
